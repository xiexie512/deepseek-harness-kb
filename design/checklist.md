# 交付前清单

用法：打印出来逐条勾。任何一条打不了勾，就回到对应文件查数值。
"查哪"列指向具体章节，不要凭记忆改。

## 一、通用（所有产出）

- [ ] 缩到 20% 仍能看出主次层次 → [SKILL.md](SKILL.md) 步骤 2
- [ ] 转灰度后层级不塌 → [foundations.md](foundations.md) 第 3 节
- [ ] 所有间距来自刻度（4/8/12/16/24/32/48/64/96） → [foundations.md](foundations.md) 第 1 节
- [ ] 字号种数 ≤ 7，且都在字阶上 → [foundations.md](foundations.md) 第 2 节
- [ ] 圆角 ≤ 3 档 → [foundations.md](foundations.md) 第 5 节
- [ ] 字体家族 ≤ 2 → [foundations.md](foundations.md) 第 2 节
- [ ] 内容宽度受限（正文 ≤ 65ch，主容器 ≤ 1280） → [foundations.md](foundations.md) 第 6 节
- [ ] 强调色占比 ≤ 10% → [foundations.md](foundations.md) 第 3 节
- [ ] 没有出现反"AI 味"清单里的任一项 → [SKILL.md](SKILL.md) 末节
- [ ] 同一类元素尺寸一致（所有按钮同高、所有卡片同圆角） → [components.md](components.md) 第 1 节

## 二、网页 / 界面

- [ ] 首屏能回答"这是什么、该做什么"
- [ ] 一屏只有一个 primary 按钮 → [components.md](components.md) 第 2 节
- [ ] 每个可交互元素有 5 态（default/hover/active/focus/disabled）
- [ ] Tab 走一遍，焦点始终可见
- [ ] 320px 宽不出现横向滚动
- [ ] 缩放 200% 不破版
- [ ] 断网 / 空数据 / 500 三个场景都有提示 → [interaction.md](interaction.md) 第 2 节
- [ ] 图片有 `alt`，图标按钮有 `aria-label`
- [ ] 表单失焦即校验，错误说清怎么改 → [interaction.md](interaction.md) 第 6 节
- [ ] 破坏性操作可撤销或二次确认

## 三、后台 / 仪表盘

- [ ] 表头、内容、筛选器左边缘对齐
- [ ] 数字右对齐 + `tabular-nums`，文字左对齐
- [ ] 表格行高统一（48 或 40，不混）
- [ ] 超过 8 列有横向滚动或列设置
- [ ] 状态用标签，不用彩色文字
- [ ] KPI 数字最大、单位最小、对比次之
- [ ] 筛选条件回显，可单个移除、可清空
- [ ] 批量操作条不遮挡内容
- [ ] 空状态区分"首次/筛选后/无权限" → [patterns.md](patterns.md) 第 6 节
- [ ] 加载用骨架屏而不是全屏转圈

## 四、移动端 / App

- [ ] 所有触控热区 ≥ 44×44
- [ ] 主按钮在拇指可达区（下 1/3）
- [ ] 安全区留白（顶部刘海、底部指示条）
- [ ] 键盘弹出不遮挡输入框
- [ ] 手势都有可见替代入口
- [ ] 正文 16px 起（不被 iOS 缩放）
- [ ] 底部 Tab ≤ 5 个
- [ ] 单屏只有一个主任务

## 五、PPT

- [ ] 每页只有一个论点，标题写结论
- [ ] 标题位置全篇一致
- [ ] 正文字号 ≥ 16pt
- [ ] 每页文字 ≤ 60 字，要点 ≤ 4 条
- [ ] 配色 ≤ 3，字体 ≤ 2
- [ ] 数据页结论先行，图表已去图例与网格线
- [ ] 过渡页留白 ≥ 70%
- [ ] 结尾有行动项，不只是"谢谢"

## 六、报告 / 文档

- [ ] 标题层级 ≤ 4 级，编号统一
- [ ] 段首缩进与段间距只用了其中一种
- [ ] 正文 12pt / 行距 1.5
- [ ] 图表有编号与标题，图下表上
- [ ] 页眉页脚齐全，封面目录无页码
- [ ] 强调只用加粗，没有彩色字
- [ ] 超过 5 页有目录
- [ ] 全篇对齐方式统一

## 七、海报 / 封面

- [ ] 信息层级 ≤ 4 层，主标题明显最大
- [ ] 留白 ≥ 30%
- [ ] 文字压图有蒙版，对比 ≥ 4.5:1
- [ ] 主标题字号是副标题的 2.5–4 倍
- [ ] 三色以内
- [ ] 二维码 ≥ 2.5cm 且有静区
- [ ] 视觉焦点只一个
- [ ] 没有四边贴满

## 八、图表

- [ ] 图型与目的匹配（比较/趋势/构成/分布/相关） → [surfaces.md](surfaces.md) 第 7 节
- [ ] 标题写结论
- [ ] 去掉 3D、阴影、渐变、多余网格线
- [ ] 分类色 ≤ 5
- [ ] 关键点直接标注，不靠图例
- [ ] 同页图表配色与字号一致
- [ ] 数字有千分位与统一小数位
- [ ] 柱状图从 0 开始

## 九、无障碍（WCAG 2.2 AA）

- [ ] 正文对比 ≥ 4.5:1，大字 ≥ 3:1
- [ ] 组件边界 ≥ 3:1
- [ ] 不只用颜色传达信息
- [ ] 焦点可见，`outline: none` 有替代
- [ ] 键盘可达全部功能，顺序合理
- [ ] 弹窗焦点锁定，Esc 可关，关闭后焦点回归
- [ ] `<html lang>` 正确
- [ ] 每页一个 `h1`，标题不跳级
- [ ] 表单有 label，错误有 `aria-describedby`
- [ ] 动态提示有 `aria-live`

## 十、交付物本身

- [ ] 命名是人能看懂的（不是 `final_v2_new`）
- [ ] 文件在约定的目录，不散落
- [ ] 给出改了什么、改成什么值的清单
- [ ] 附机器审查分数（有 HTML/CSS 时）
- [ ] 说明哪些是刻意为之（例如品牌必须用高饱和色）
