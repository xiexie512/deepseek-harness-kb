## 1. 间距刻度

刻度：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`

### 语义映射

| 值 | 用途 | 典型位置 |
|---|---|---|
| 4 | 紧耦合 | 图标与文字、标签与数值、徽标内边距 |
| 8 | 控件内部 | 小按钮左右内边距、列表项图标间距 |
| 12 | 紧凑分组 | 表单字段之间（紧凑模式）、表格纵向内边距 |
| 16 | 标准内边距 | 卡片内边距、标准按钮内边距、段落间距 |
| 24 | 组与组 | 卡片与卡片、区块内分组、桌面卡片内边距 |
| 32 | 小节 | 区块内小节、移动端内容左右留白 |
| 48 | 区块 | 区块之间、页面小节分隔 |
| 64 / 96 | 页面级 | 大分区、Hero 上下、大屏留白 |

### 硬规则

1. **组内 ≤ 组间的一半。** 做不到说明分组错了，先改分组。
2. `padding` / `margin` / `gap` 只取刻度值。需要 1px 视觉缝用 `border` 或 `box-shadow`，不要用奇数间距凑。
3. 用父级 `gap` 统一控制间距，不要逐个 `margin-bottom` 堆——最后无法整体调整。
4. 密度三档，同一产品只用一档：

| 档位 | 间距集合 | 适用 |
|---|---|---|
| 紧凑 | 4 / 8 / 12 / 16 | 数据密集型后台、表格页 |
| 标准 | 4 / 8 / 16 / 24 | 大多数界面 |
| 宽松 | 8 / 16 / 32 / 48 | 营销页、品牌页、阅读型页面 |

### 常见错误

- 所有间距都是 16px → 没有分组，全页散沙。
- 卡片内边距 20、卡片间距 20 → 容器与容器的关系读不出来。
- 用 `<br>` 或空 div 堆间距 → 无法维护。
- 移动端沿用桌面间距 → 挤成一团。

## 2. 字体系统

### 字阶表（桌面基准，移动端降一档）

| Token | 字号 | 行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|---|
| display | 60 | 64 | 700 | -0.02em | 大型展示、Hero |
| h1 | 48 | 52 | 700 | -0.02em | 页面主标题 |
| h2 | 36 | 44 | 700 | -0.01em | 区块标题 |
| h3 | 30 | 38 | 600 | -0.01em | 小节标题 |
| h4 | 24 | 32 | 600 | 0 | 卡片标题 |
| h5 | 20 | 28 | 600 | 0 | 列表组标题 |
| lead | 18 | 28 | 500 | 0 | 引导文、摘要 |
| body | 16 | 26 | 400 | 0 | 正文 |
| body-sm | 14 | 20 | 400 | 0 | 次要正文、表格 |
| label | 12 | 16 | 500 | 0.06em | 标签、脚注（全大写时） |

### 规则

- **字体家族 ≤ 2**。中文栈：`-apple-system, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`。为"高级感"混用三种以上，只会显得没统一。
- **字重只用 400 / 500 / 600 / 700。** 不用 300 做正文——细体在低分屏和浅底上直接糊掉。
- **中文行高比英文 +0.05～0.1。** 中文 16px 正文行高至少 26px，1.4 会显得挤。
- **中文正文不小于 14px**；移动端正文 **16px 起**（低于 16px，iOS 聚焦输入框会自动缩放页面）。
- 大字号用负字距（-0.01～-0.02em），小字号用正字距（+0.01em），全大写标签 +0.06em。
- 数字列启用 `font-variant-numeric: tabular-nums`，表格与金额必须对齐。
- **行长 45–75 字符**（`max-width: 65ch`）；中文按每行 25–40 字控制。
- **行高按用途分，不按字号统一**：标题 1.05–1.25、正文 1.5–1.75、标签 1.3–1.4。

### 字体选型

| 场景 | 建议 |
|---|---|
| 中文界面 | 苹方 / 思源黑体 / 微软雅黑，系统栈优先，不引外部字体 |
| 中文长文阅读 | 思源宋体、方正书宋；行高放宽到 1.75 |
| 数字密集（后台、金额） | 无衬线 + tabular-nums；可用等宽做金额列 |
| 品牌主视觉 | 一个有个性的标题字体 + 一个中性正文字体，形成对比 |
| 表白/海报短句 | 衬线或手写体，但只用于标题，不用于正文 |

### 排版细节（做了就显专业）

- 中英文之间加空格："使用 Figma 设计"，不是"使用Figma设计"。
- 数字与单位统一写法（`16px` 或 `16 px`，全篇一致）。
- 段间距用 `margin` / `gap`，不用空行堆。
- 标题与它的正文 8–12px；标题与上一组 32–48px。
- 引号用中文引号「」或""，全篇统一；破折号、省略号用中文形态。
- 同级标题不换字号；跳级只允许 h1 → h3 这类结构上的真实跳级，但要显式说明。

### 常见错误

- 正文 12px + 行高 1.2，看起来像说明书。
- 所有文字一个字号，靠加粗区分层级。
- 标题居中、正文居中、按钮居中，三连居中。
- 每段都是 3 行，视觉上像墙。

## 3. 色彩系统

### 结构：三层命名

```css
/* 原始层 */ --blue-500: #2563eb;
/* 语义层 */ --color-primary: var(--blue-600);
/* 组件层 */ --button-bg: var(--color-primary);
```

只允许组件层引用语义层，语义层引用原始层。业务样式里直接写 `#2563eb`，换主题必然崩。

### 中性阶（9 档，带色相）

| 档 | 冷调（偏蓝） | 用途 |
|---|---|---|
| 50 | `#f8fafc` | 页面底、浅底块 |
| 100 | `#f1f5f9` | 次级面、hover 底 |
| 200 | `#e2e8f0` | 描边、分隔线 |
| 300 | `#cbd5e1` | 强描边、禁用边框 |
| 400 | `#94a3b8` | 占位符、禁用文字 |
| 500 | `#64748b` | 三级文字 |
| 600 | `#475569` | 二级文字 |
| 700 | `#334155` | 强调正文 |
| 800 | `#1e293b` | 标题 |
| 900 | `#0f172a` | 主标题、最深底 |

暖调版把色相往 30–40° 偏，例：`#78716c` 系。

**最深不用 `#000`，最浅不用 `#fff`。** `#0f172a` / `#f8fafc` 更贵，也更耐看。

### 文字三级

| 层级 | 值 | 白底对比 | 用途 |
|---|---|---|---|
| 主 | `#111827` | 16.7:1 | 标题、正文、关键数据 |
| 次 | `#4b5563` | 8.6:1 | 说明、表格、辅助信息 |
| 弱 | `#9ca3af` | 2.9:1 | 占位符、禁用、非关键脚注 |

**`#9ca3af` 只有 2.9:1，不达 AA。** 凡是用户需要读的文字，最浅用 `#6b7280`（4.6:1）。

### 品牌色阶

以种子色为 500，向亮向暗各推四档，饱和度向两端递减：

| 档 | 用途 |
|---|---|
| 50 / 100 | 选中底、提示底、标签底 |
| 200 / 300 | 描边、进度条底 |
| 400 | 暗色模式主色 |
| **500** | 主按钮、链接、图标（若白字不达标则降级到 600） |
| 600 | 主按钮（默认取这档更稳）、hover |
| 700 | active、白底上的深色文字 |
| 800 / 900 | 深色标题、暗底强调 |

### 视觉权重 60 / 30 / 10

| 占比 | 内容 |
|---|---|
| 60% | 中性底、留白、卡片面 |
| 30% | 文字、描边、非激活态、次级面 |
| 10% | 强调色：CTA、选中、数据高亮、焦点环 |

**最常见错误**：把品牌色铺满导航、卡片、图表、图标——结果没有任何东西突出。

### 语义色

每种三件套：`bg`（浅底）、`border`、`text`（深字）。

| 语义 | text | bg | 用途 |
|---|---|---|---|
| success | `#15803d` | `#f0fdf4` | 完成、通过、正向变化 |
| warning | `#b45309` | `#fffbeb` | 需要注意但可继续 |
| error | `#b91c1c` | `#fef2f2` | 失败、阻断 |
| info | `#1d4ed8` | `#eff6ff` | 中性提示 |

状态色不能只做文字色，要配底色和图标。

### 暗色模式

**不是反色，是重新映射。**

| 层 | 值 | 说明 |
|---|---|---|
| background | `#0f1115` | 页底，带一点蓝 |
| surface | `#171a1f` | 卡片、面板 |
| surface-raised | `#1f242b` | 弹层、下拉、hover 面 |
| border | `#2a3038` | 分隔线 |
| text-primary | `rgba(255,255,255,.87)` | 不用纯白 |
| text-secondary | `rgba(255,255,255,.60)` | |
| text-tertiary | `rgba(255,255,255,.38)` | |

- **抬高 = 变亮**（和亮色模式同方向），不是变暗。
- 品牌色在暗底降饱和 10–20%、提亮一档（500 → 400），否则刺眼。
- 阴影在暗色几乎不可见，靠"表面提亮 + 1px 亮边"表达层级。
- 纯黑 `#000` 配纯白字会产生光晕（halation），读久了累。

### 用色禁忌

| 禁忌 | 原因 |
|---|---|
| 灰字放在彩色底上 | 灰与任何彩色都打架；改用该色的深色版本 |
| 浅灰占位符当正文 | 4.5:1 不达标，等于没做无障碍 |
| 只靠颜色区分状态 | 色盲用户无法识别 |
| 一个页面 8 种颜色 | 无主色，等于没有品牌色 |
| 红配绿做相邻状态 | 对比过强且有文化歧义 |
| 大面积高饱和纯色 | 刺眼、廉价；降低明度或缩小面积 |

## 4. 阴影与层级

双层结构：一层**贴合**（小、深、边缘清晰）+ 一层**氛围**（大、淡、柔和）。单层阴影永远像 PS 默认效果。

```css
--shadow-0: none;
--shadow-1: 0 1px 2px rgba(15,23,42,.06), 0 1px 1px rgba(15,23,42,.04);
--shadow-2: 0 4px 8px -2px rgba(15,23,42,.08), 0 2px 4px -2px rgba(15,23,42,.06);
--shadow-3: 0 12px 24px -6px rgba(15,23,42,.12), 0 4px 8px -4px rgba(15,23,42,.08);
--shadow-4: 0 24px 48px -12px rgba(15,23,42,.18), 0 8px 16px -8px rgba(15,23,42,.10);
```

| 级 | 用途 |
|---|---|
| 0 | 普通卡片、页面区块（用间距和描边区分） |
| 1 | 输入框、轻微抬起的卡片、标签 |
| 2 | 下拉菜单、悬浮按钮、可拖拽项 |
| 3 | 弹窗、抽屉、Toast |
| 4 | 全屏模态、命令面板 |

### 规则

- 阴影颜色**带色相**（`rgba(15,23,42,…)` 是冷调深色），不用纯灰 `rgba(0,0,0,.1)`。
- **不要什么都加阴影。** 如果所有元素都浮起来，就没有东西浮起来。
- 层级优先用"间距 + 表面色差"表达，阴影是最后手段。
- 阴影不要配粗描边，两者叠加会显脏。
- hover 升一级阴影 + `translateY(-2px)`，200ms 内完成，不要弹跳。

## 5. 圆角与描边

| 圆角 | 用途 |
|---|---|
| 4 | 标签、徽标、小输入框、复选框 |
| 8 | 按钮、输入框、卡片（默认） |
| 12 | 卡片、面板、图片容器 |
| 16 | 大容器、模态、移动端卡片 |
| 999 | 胶囊按钮、头像、开关 |

- 同一界面最多 3 档。按钮 8 + 卡片 8 + 标签 4 就够。
- **嵌套圆角**：内层 = 外层 − 内边距。卡片 12、内边距 4 的图片 → 图片圆角 8。
- 圆角与尺寸成比例：24px 高的标签用 12px 圆角就是胶囊，不是"圆角"。
- 描边用 `1px solid` + 浅色（`#e2e8f0`），不要 2px 深色描边。更轻的分隔用 `rgba(15,23,42,.06)`。

## 6. 栅格与布局模式

| 断点 | 容器 | 列 / gutter | 页边距 |
|---|---|---|---|
| < 640 手机 | 100% | 4 列 / 16 | 16 |
| 640–1024 平板 | 100% | 8 列 / 24 | 24 |
| 1024–1280 小桌面 | 1024 | 12 列 / 24 | 32 |
| 1280–1536 桌面 | 1280 | 12 列 / 24 | 32 |
| > 1536 大屏 | 1440 | 12 列 / 32 | 48 |

- 内容容器上限 1280；**阅读型内容（文章、文档、表单）再收窄到 720–840**。
- 卡片网格用 `repeat(auto-fill, minmax(280px, 1fr))` + `gap: 24px`，比写死列数稳。
- 对齐轴 ≤ 2。默认左对齐 + 顶部对齐。
- **打破等分**：2/3 + 1/3、大卡 + 小卡、错位高度，是一眼区别于模板感的关键。

### 五种常用布局

| 模式 | 结构 | 适用 | 注意 |
|---|---|---|---|
| 单列阅读 | 居中窄容器，单列流 | 文章、文档、设置 | 容器 720–840，行长 ≤ 65ch |
| 两栏主次 | 左侧 1/3 辅助 + 右侧 2/3 主内容 | 详情页、设置页 | 主栏可滚动，辅助栏固定 |
| 卡片网格 | 3–4 列，等高卡片 | 列表、作品集、功能 | 卡片数不是 3 的倍数时避免空洞 |
| 看板 | 多列，等宽，可横向滚动 | 任务、状态流 | 列头固定，卡片高度不齐 |
| 分屏工作区 | 导航 + 列表 + 详情（三栏） | 邮件、IM、IDE 类 | 明确哪一栏是主要视线 |

## 7. 图标

| 尺寸 | 用途 |
|---|---|
| 16 | 行内（文字旁、表格操作） |
| 20 | 输入框前后缀、按钮内 |
| 24 | 导航栏、列表项、独立按钮 |
| 32 | 功能入口、空状态辅助 |
| 48+ | 空状态主图、引导页 |

- 一套图标库，**线宽一致**（1.5 或 2px），不要混用线性与面性。
- 图标与文字基线对齐，垂直居中靠 flex，不靠 `margin-top` 手调。
- 图标 + 文字的间距 4–8px；图标单独做按钮时热区 ≥ 44×44。
- 装饰图标 `aria-hidden="true"`；纯图标按钮必须有 `aria-label`。
- 不用 emoji 当图标——跨平台渲染不一致，风格不可控。

## 8. 图片

- **永远不拉伸**：`object-fit: cover` + 固定 `aspect-ratio`。
- 统一圆角；圆角跟随容器，内层 = 外层 − 内边距。
- 文字压图必须加蒙版：`linear-gradient(to top, rgba(0,0,0,.7), transparent)`，对比仍要 ≥ 4.5:1。
- 头像统一尺寸（24 / 32 / 40 / 48），圆形或圆角 4，加载失败用首字母兜底。
- 提供 `width` / `height` 或 `aspect-ratio` 防位移；首屏图加 `loading="eager"`，其余 `lazy`。
- 图片比例统一：要么全 16:9，要么全 4:3，不要混。
- 插画风格全站统一（同一作者/同一套色），混用图库素材最显廉价。

## 9. CSS token 与本文件的关系

本文的每个数值在 [tokens.css](tokens.css) 里都有对应变量，命令生成：

```sh
python3 scripts/make_tokens.py --seed "#2563eb" --mode both --out tokens.css
```

生成的变量覆盖：品牌 9 档、中性 10 档、间距 9 档、字号 10 档、行高 4 档、字重/字距、圆角 5 档、阴影 4 级、动效 3 时长 + 3 曲线、容器宽度、语义色、亮/暗两套映射。

**改刻度就改脚本、重生成，不要手改变量文件**——否则下次重生成会把改动冲掉。
