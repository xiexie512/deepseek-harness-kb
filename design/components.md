# 组件规格

组件是稳定性的来源。同一个组件在不同页面出现两种高度、两种圆角，整站立刻显得业余。

## 1. 通用规则

### 尺寸三档

| 档 | 高度 | 字号 | 横向内边距 | 圆角 | 用在哪 |
|---|---|---|---|---|---|
| sm | 32 | 14 | 12 | 6–8 | 表格行内操作、工具条 |
| md | 40 | 14–16 | 16 | 8 | 默认 |
| lg | 48 | 16 | 20–24 | 8–12 | 表单主按钮、营销页、移动端 |

**同一屏只用一到两档。** 一个表单里出现 32、40、44、48 四种高度，是没定规范。

### 五态必做

| 状态 | 表现 |
|---|---|
| default | 基础样式 |
| hover | 底色加深一档 / 描边加深；不改变尺寸 |
| active | 再深一档 + `scale(.98)` 或内阴影，100ms |
| focus-visible | `outline: 2px solid` + `outline-offset: 2px`，键盘可达才显示 |
| disabled | 降透明度到 40–50%，`cursor: not-allowed`，**不响应 hover** |

补充两态：loading（按钮内 spinner + 保留原位）、read-only（看起来像输入框但不可编辑，底色不同）。

### 间距

- 同组按钮间距 8；不同组 16–24。
- 图标与文字 4–8。
- 控件的标签在上方，间距 4–8；错误文案在下方，间距 4。

### 无障碍底线

- 触控热区 ≥ 44×44（视觉可以小，用 padding / 伪元素扩大）。
- 原生元素优先：`<button>` 而不是 `<div class="btn">`。
- 图标按钮必须有 `aria-label`。
- 禁用态用 `disabled` 属性，不要只靠样式。

## 2. 按钮

### 层级

| 类型 | 样式 | 每屏数量 |
|---|---|---|
| primary | 实心品牌色 + 白字 | 1 |
| secondary | 描边或浅底 | 1–2 |
| tertiary / text | 无底，只有文字 | 不限 |
| danger | 实心红，仅用于不可逆操作 | 0–1 |

**一屏只能有一个 primary。** 两个同等重的按钮，等于没有主行动。

### 规格

| 项 | sm | md | lg |
|---|---|---|---|
| 高度 | 32 | 40 | 48 |
| 字号 / 字重 | 14 / 500 | 14–16 / 500 | 16 / 500 |
| 左右内边距 | 12 | 16 | 20–24 |
| 圆角 | 6–8 | 8 | 8–12 |
| 图标尺寸 | 14–16 | 16 | 18–20 |

- 文案是**动词 + 结果**："保存并发布""发送邀请"，不写"提交""确定"。
- 按钮宽度：表单主按钮可撑满（移动端），其余按内容宽度；同组按钮宽度一致。
- 加载时保留按钮宽度，不要把文字换成纯 spinner（会跳）。
- 危险操作按钮默认不用 primary 实心红，避免误触；放在次要位置。

### 反例

- 三个按钮并排：实心蓝 + 实心绿 + 实心红。
- 按钮文案"确定 / 取消 / 提交 / 保存"混在同一表单。
- hover 时改变尺寸（padding 变化导致抖动）。

## 3. 输入框与表单控件

| 项 | 值 |
|---|---|
| 高度 | 36–40（md），48（移动端） |
| 内边距 | 左右 12–16，上下 8–10 |
| 圆角 | 8 |
| 描边 | 1px `#e2e8f0`，focus 时品牌色 + 2px 外环 |
| 标签 | 在上方，14px，字重 500，次要色 |
| 帮助文案 | 标签下方或字段下方，12–13px，弱色 |
| 错误文案 | 字段下方，12–13px，错误色 + 图标 |
| 占位符 | 只能是示例，不能替代标签 |

### 规则

- 输入类型要对：`email` / `tel` / `number` / `url` / `search`，移动端会调对应键盘。
- 必填标记 `*` + 可选字段写"（选填）"，比满屏红星清楚。
- 失焦时校验，不要每敲一字报错。
- 错误时：描边变红 + 文案 + 图标，三者齐全。
- 提交失败保留全部输入，聚焦第一个错误字段。
- 长表单分组，每组 3–7 个字段。
- 前缀/后缀图标放在框内，与文字间距 8。

### 文本域

- 最小高度 3 行，可纵向拉伸，禁止横向拉伸。
- 显示字数上限时，接近上限才出现计数（如 200 字限制，180 字起显示）。
- 段落型输入行高 1.5–1.6。

## 4. 选择类控件

### 下拉选择

| 项 | 值 |
|---|---|
| 触发区高度 | 36–40 |
| 选项高度 | 36–40，内边距 12 |
| 面板圆角 / 阴影 | 8 / shadow-2 |
| 面板最大高度 | 320，超出滚动 |
| 选中态 | 左侧勾 + 浅底 |

- 选项 ≤ 5 用单选按钮平铺；> 5 用下拉；> 30 带搜索。
- 下拉面板宽度 ≥ 触发区宽度。
- 键盘：↑↓ 移动、Enter 选中、Esc 关闭。

### 复选框 / 单选 / 开关

| 控件 | 尺寸 | 热区 | 用于 |
|---|---|---|---|
| 复选框 | 16–20 方框 | 整行可点 | 多选、确认条款 |
| 单选 | 16–20 圆 | 整行可点 | 2–5 个互斥选项 |
| 开关 | 40×22 轨道 | 44×44 | 立即生效的开关（不是提交式） |

- 开关用于"立即生效"，勾选框用于"随表单一起提交"。混用会让用户误以为已保存。
- 选项文字可点，不要只有小方框可点。

## 5. 表格

| 项 | 宽松 | 紧凑 |
|---|---|---|
| 行高 | 56 | 40 |
| 左右内边距 | 16 | 12 |
| 上下内边距 | 12 | 8 |
| 表头字号 | 13 / 500 | 12 / 500 |
| 单元格字号 | 14 | 13–14 |
| 分隔线 | 横线 `#f1f5f9` | 横线更淡或仅 hover 显示 |

### 规则

- **表头弱化，数据强化**：表头 12–13px + 次级色，数据 14px + 主色。
- **数字右对齐 + tabular-nums**，文字左对齐，日期全站统一（建议左对齐）。
- 超过 8 列：固定前 2 列，横向滚动；或做列显示设置。
- 行 hover 底色 `#f8fafc`；选中行加左侧 3px 品牌色条，不要整行染色。
- 操作列固定在右侧，最多 3 个文字操作 + "更多"。
- 空状态占满表格区域，不要只留一行"暂无数据"。
- 排序、筛选状态要可见（表头箭头 + 已选筛选条件 chips）。
- 批量操作：选中后顶部浮现操作条，含已选数量 + 清空。

### 反例

- 斑马纹 + 全边框 + 竖线，三重分隔。
- 所有列居中。
- 表头和数据同字号同颜色。
- 分页器写在表格上方。

## 6. 卡片与列表

### 卡片

| 项 | 值 |
|---|---|
| 内边距 | 16（紧凑）/ 24（标准） |
| 圆角 | 12 |
| 描边 | 1px `#e2e8f0` 或 shadow-1，二选一 |
| 标题 | 20–24 / 600 |
| 间距 | 卡片之间 24 |

- 一张卡只表达一件事。卡片里放三个不相关模块，等于没分模块。
- 卡片可点击时整卡是热区，并给 hover 反馈。
- 图片在卡片里要出血（贴边）或统一内缩，不要一半出血一半留白。

### 列表项

| 项 | 值 |
|---|---|
| 高度 | 56–72 |
| 左右内边距 | 16 |
| 图标 | 24（左），箭头 16（右） |
| 分隔线 | 只左侧缩进 16，或不用线只用间距 |

- 主文案 16/500，副文案 14/次级色。
- 右侧信息（时间、状态、金额）右对齐，与箭头间距 8。
- 超过 7 项要分组或加搜索。

## 7. 弹窗 / 抽屉 / 气泡

### 选择哪种容器

| 场景 | 用 |
|---|---|
| 需要专注完成的小任务（重命名、确认） | 模态弹窗 |
| 需要保留页面上下文的侧边内容（详情、设置） | 抽屉 |
| 只展示少量信息、不阻断 | 气泡卡片 / Popover |
| 移动端从底部出现的选择/操作 | 底部抽屉（Sheet） |

### 模态弹窗

| 项 | 值 |
|---|---|
| 宽度 | 400（小）/ 560（中）/ 720（大），不超过 80% 屏宽 |
| 内边距 | 24 |
| 圆角 | 16 |
| 阴影 | shadow-4 |
| 遮罩 | `rgba(15,23,42,.4)`，带 4px 模糊可选 |
| 标题 | 20 / 600，与内容间距 16 |
| 按钮区 | 右下，间距 8，主按钮在右 |

- 焦点锁在弹窗内，Esc 关闭，关闭后焦点回到触发元素。
- 点击遮罩是否关闭：表单类不关闭（防丢数据），确认类可关闭。
- 标题写清在做什么（"删除 3 个项目？"），不要写"提示"。
- 长内容在弹窗内滚动，不要撑高整页。

### 抽屉

- 宽度 360–480，从右侧滑入，200–300ms。
- 顶部固定标题栏 + 关闭；底部固定操作栏；中间滚动。
- 移动端改为全屏或底部 Sheet。

## 8. 提示类

| 类型 | 位置 | 停留 | 用途 |
|---|---|---|---|
| Toast | 顶部居中或底部居中 | 3–5s，可关闭 | 轻量结果反馈 |
| Inline alert | 内容区内嵌 | 常驻 | 需要用户注意的说明 |
| Banner | 页面顶部通栏 | 常驻 | 全局状态（离线、试用到期） |
| Tooltip | 元素旁 | hover/focus 显示 | 解释图标含义 |

### 规则

- Toast 不遮挡主操作，一次只显示 1–2 条，多了排队。
- 成功用绿色 + 对勾，失败用红色 + 警告图标，**颜色之外必须有图标**。
- 错误提示必须带"怎么办"：重试按钮或下一步建议。
- Tooltip 只放一句话，超过就改成帮助文档链接。
- Banner 必须可关闭（除非是阻断性状态）。

## 9. 导航类

### 顶部导航

| 项 | 值 |
|---|---|
| 高度 | 64–72 |
| 左右内边距 | 匹配容器边距 |
| Logo 与入口间距 | 32–40 |
| 入口间距 | 24–32 |
| 层级 | Logo + 4–6 入口 + 1 主 CTA |

- 吸顶时加半透明底 + 1px 下边线，不要只靠阴影。
- 当前页要有选中态（下划线或加粗），不能所有入口一样。

### 侧边导航（后台）

| 项 | 值 |
|---|---|
| 宽度 | 200–240（可折叠到 48） |
| 项高度 | 40–44 |
| 分组标题 | 12 / 500 / 弱色 |
| 选中态 | 左侧 3px 品牌色 + 浅底 |

- 分组不超过 3 级；超过就把二级做成页面内 Tab。
- 折叠状态保留图标 + Tooltip。

### Tab

- 2–7 个；超过 7 个改用下拉或分组。
- 选中态用下划线或浅底，不要两者都用。
- 内容区与 Tab 间距 16–24。

### 面包屑

- 层级 ≥ 3 才需要。
- 只显示路径，不加"首页 > "这类多余前缀（除非确实需要回首页）。
- 最后一级不可点击，且与页面标题一致。

## 10. 状态类

### 空状态

| 组成 | 要求 |
|---|---|
| 一句人话 | "还没有项目"而不是"暂无数据" |
| 一个动作 | 主按钮，明确指出下一步 |
| 可选插图 | 与产品风格一致，不要通用图库素材 |
| 可选引导 | 2–3 条"你可以做什么" |

区分三种空：**首次为空**（给引导）、**筛选后为空**（给清空筛选）、**无权限为空**（给申请入口）。

### 加载

| 时长 | 形式 |
|---|---|
| < 300ms | 不显示（会闪） |
| 300ms–1s | 骨架屏（保留布局结构） |
| 1–10s | 进度条 / 阶段文案 |
| > 10s | 转异步任务 + 完成通知 |

### 骨架屏

- 形状要匹配真实内容（列表就画行，卡片就画块）。
- 动画用低对比的 shimmer，频率 1.2–1.6s，幅度小。
- 不要整页骨架，优先骨架主内容区。

### 进度与步骤条

- 步骤条 2–5 步；超过 5 步合并。
- 显示"第 2 步 / 共 4 步"，不要只画点。
- 当前步高亮，已完成步打勾，未开始步弱化。

## 11. 组件清单速查

| 组件 | 默认高度 | 圆角 | 关键状态 |
|---|---|---|---|
| Button | 40 | 8 | 5 态 + loading |
| Input | 40 | 8 | default / focus / error / disabled |
| Select | 40 | 8 | open / selected / disabled |
| Checkbox | 18 框 | 4 | checked / indeterminate |
| Switch | 40×22 | 999 | on / off / disabled |
| Table row | 48 | — | hover / selected |
| Card | — | 12 | hover（可点击时） |
| Modal | 400–720 宽 | 16 | open / loading / error |
| Drawer | 360–480 宽 | 0–16 | open / closing |
| Toast | 40 高 | 8 | info / success / error |
| Tooltip | 自适应 | 6 | 显示 / 隐藏（150ms） |
| Tab | 40–44 | 0 | active / hover |
| Badge | 20 | 4 | 语义色 × 4 |
| Avatar | 24/32/40/48 | 圆或 4 | 有图 / 首字母兜底 |
| Pagination | 32 | 6 | active / disabled |
| Empty | — | — | 首次 / 筛选后 / 无权限 |

新增组件时，先在这张表里登记尺寸和状态，再写样式——否则一定会长出第四种高度。
